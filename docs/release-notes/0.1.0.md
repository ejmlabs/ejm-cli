# ejm-cli 0.1.0

Draft. This early release is from the lab. It is not published until a maintainer publishes the GitHub release.

## What this is

ejm-cli is a terminal coding agent built on ejm-harness. Version 0.1.0 is the first packaged build. Expect rough edges and report them with the links below.

Built with ejm-harness revision `42e4f9cf33bd3525aec344cfdffabc251271f782`. The same revision is written to `HARNESS_REVISION` inside each archive.

## Platforms

| Platform | Download | Notes |
| --- | --- | --- |
| Linux x86_64 | `ejm-cli-0.1.0-x86_64-unknown-linux-gnu.tar.gz` | Needs glibc 2.39 or later (Ubuntu 24.04, Debian 13) and `libdbus-1`. Stored sign-in needs a session D-Bus with an unlocked Secret Service. |
| macOS Apple silicon | Not yet available | The build is waiting for notarization. No macOS file is offered. |
| macOS Intel, Windows | Not yet available | Not built. |

Older distributions such as Debian 12 and Ubuntu 22.04 fail at launch with the loader's message. Without a Secret Service the program still starts and `ejm-cli --replay` works, but stored credentials are unavailable.

Open evidence from the repository (native Linux acceptance for the shared process and credential code in ejm-harness, and live remote-control acceptance, see `CHANGELOG.md` and `docs/native-remote-publication.md`) remains a known limit for this release.

## Not signed, not notarized

These builds are not signed with a developer certificate and are not notarized. Checksums and the build's provenance record do not change that. A checksum shows the file matches what was published. It does not show who built it, and it would not catch a compromise of the place that publishes both the file and the checksum.

## Check and install

```sh
sha256sum --check --ignore-missing SHA256SUMS
tar -xzf ejm-cli-0.1.0-x86_64-unknown-linux-gnu.tar.gz
./ejm-cli-0.1.0-x86_64-unknown-linux-gnu/ejm-cli --version
```

The version line must read `ejm-cli 0.1.0`. Move the `ejm-cli` binary to any directory on your `PATH`. The archive also holds `LICENSE` and `THIRD_PARTY_NOTICES.md`.
